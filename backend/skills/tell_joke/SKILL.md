# 讲笑话技能

## 功能说明

从预置的笑话列表中随机讲一个程序员笑话，适合活跃气氛。

## 使用步骤

1. 使用 ``python_repl`` 执行以下代码：

```python
import random

jokes = [
    "为什么程序员总是搞混万圣节和圣诞节？\n因为 Oct 31 == Dec 25（八进制31 = 十进制25）",
    "程序员最讨厌什么季节？\n秋天，因为要处理大量的 fall-through。",
    "一个 SQL 语句走进酒吧，看到两张 table，问：Can I JOIN you?",
    "为什么 Java 开发者要戴眼镜？\n因为他们看不到 C#。",
    "世界上最遥远的距离不是生与死，而是你亲手写的 bug 就在你眼前，你却怎么都找不到它。",
    "老板：这个项目什么时候能完成？\n程序员：下周五。\n老板：哪一年的？",
    "debug 的六个阶段：1.不可能 2.我机器上没问题 3.不应该 4.为什么会这样 5.哦 6.原来一直都是这样",
]

joke = random.choice(jokes)
print(joke)
```

2. 将输出的笑话以轻松的语气展示给用户。

## 输出格式

用 emoji 和轻松的语气展示，例如：

> 😄 **今日笑话**
>
> （笑话内容）

## 注意事项

- 这是一个纯本地技能，不需要网络
- 每次调用随机选择，可能会重复
